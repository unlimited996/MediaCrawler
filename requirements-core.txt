# 分层原则
# --------
# library 只做「查/增/删/改 + 配置 + S3 备份 + 前端静态页 + 按服务名转发」，

# 被拖进 playwright / opencv / matplotlib / jieba / wordcloud / pandas / numpy，
# 1.61GB 的镜像里约 700MB 是 library 一辈子用不到的东西，跨境推送极慢。
#
# 维护约定：往这里加包前，先确认 library 的接口真的会调用；
# 纯爬虫用的（opencv/playwright/matplotlib...）放 requirements-crawler.txt。
# =============================================================================
